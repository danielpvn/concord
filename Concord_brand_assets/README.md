# Concord — Brand Assets

Master icon and platform-ready exports generated from the approved Concord mark.

## Included
- Web: favicon.ico, PNG 16–1024px, WebP
- PWA: 192px and 512px + site.webmanifest
- iOS: common AppIcon sizes
- Android: mdpi through xxxhdpi + 512px store icon
- Windows: multi-resolution ICO
- macOS: ICNS when supported by the image library
- SVG: embedded PNG wrapper for easy web embedding (not a true vector redraw)

## Recommended
- Keep `concord-icon-master-1024.png` as the source/master raster.
- Use PNG for app stores and adaptive/icon pipelines.
- Use `favicon.ico` for broad browser compatibility.
- For a truly scalable SVG, the mascot should be redrawn as vector paths rather than auto-wrapped raster.
