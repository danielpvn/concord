## Common web / product widths
Exports from 320px through 3840px wide.

## Recommended usage
- Dark/gradient backgrounds: use the main gradient or white version.
- Light backgrounds: use the dark version when contrast is needed.
- Website navigation: 320–800px source is generally sufficient; render responsively.
- Hero sections / large desktop: use 1600px+.
- Email signatures: use the provided email-signature asset.
- Do not stretch the wordmark; always preserve aspect ratio.

## Important
The SVG files are raster-image SVG wrappers. For a fully scalable production identity, the lettering should eventually be converted into true vector paths.
